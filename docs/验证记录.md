## 新动作专项调试

- 正常执行验证名义时长 4200 ms、左右倾斜目标、三次摇尾峰值、最终站立、开心表情及原尾巴使能状态。起点包含站立和原来的放松趴下姿态。
- 检查 20 ms 帧间输出连续性，测试起点下每通道角度变化不超过约 5°；重复触发后从当前下发角度插值。
- 在 28 个时间边界注入新指令，组合两路来源、原尾巴开/关以及趴下、站立、跳跃、重复卖萌、摇尾开关，验证新请求不被旧完成流程覆盖。
- 发现并修复收尾表情问题：卖萌最后一毫秒收到达到速度上限的调速命令时，旧实现会停留在狂热表情。增加回归断言并先确认其失败，再让正常完成明确恢复开心表情；中断退出仍保留新请求的表情。
- 主循环集成测试实际分派 `0x50` 并推进到动作完成，确认正常回到站立而非重复卖萌。

## 复现

```sh
cd /workspace/dog
bash tests/run.sh
SANITIZE=1 bash tests/run.sh
```

当前机器 ARM 工具链以 Debian 签名索引及包 SHA-256 校验后解包到工作区，没有替换系统工具。当前路径下的 ARM 检查命令为：

```sh
ARM_CC=/workspace/tools/arm-check/root/usr/bin/arm-none-eabi-gcc \
NEWLIB_INCLUDE=/workspace/tools/arm-check/root/usr/include/newlib \
bash tests/check_arm.sh
```

其他机器可安装常规 ARM GNU 工具链，再直接运行 `bash tests/check_arm.sh`。工具链和测试生成的二进制文件不包含在源码包内。

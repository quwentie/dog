# 交付说明

本版包含控制通信修复与已确认的趣味动作“撒娇求摸摸”。源码位于 `HardWare/`、`User/`，保留原 Keil 工程布局及作者说明。标准外设库和启动代码随包提供。

## 做了什么

| 文件 | 改动 |
|---|---|
| `HardWare/BlueTooth.c/.h` | 中断只收字节、63 条接收队列、SR/DR 单次读取、错误及溢出计数、共用前台解析、表情刷新合并、请求编号、摇尾关闭修复、新增 0x50 |
| `HardWare/PetAction.c/.h` | 所有动作等待可处理新指令，防止旧动作回写、计数下溢修复、头文件保护修复、新增 4.2 秒撒娇动作和渐变控制 |
| `HardWare/Servo.c/.h` | 记录最近一次下发的角度供插值使用，保持原有 PWM 映射与左右反向关系 |
| `User/main.c` | 初始化中断分组、前台处理指令、修复旧动作返回后的尾巴回写、分派撒娇动作 |
| `tests/` | 实际业务源码的主机测试、ARM 目标文件编译检查及硬件边界替身 |

## 如何体验新动作

在已有蓝牙串口链路上，串口助手设为 9600、8N1，以 HEX 模式发送 `50`。它会瞪眼压低身体、左右轻倾、开心摇尾三次并站立。也可以直接发送 ASCII 大写 `P`，二者均为单字节 0x50。

新动作不要求修改 Keil 项目文件或新增硬件。已有语音模块只有输出 0x50 才能触发此动作，具体语音词条配置依赖模块工具。

动作期间发送其他动作会接管；重复发送 0x50 会从当前下发角度重新开始。灯光与调速可继续使用。本动作固定节奏，调速仅修改原步态参数。正常完成保留原尾巴开关状态，中途接管不会恢复过期状态。

## 检验与使用边界

1298 个主机回归场景通过，ASan/UBSan 检查通过；5 个 Cortex-M3 目标文件编译通过。详细复现命令和调试记录见 `验证记录.md`。

当前交付的是源码包。需用原 Keil 工具链 Rebuild 完成汇编、链接及空间检查，才能生成新版 HEX；当前尚未验证实机姿态、动作时延和机械行程。渐变读取的是软件记录的目标角度，并非舵机位置反馈。

压缩包不含旧 HEX/AXF，以免将原有固件误认为本版产物。补丁仅用于对照或应用到原始 2 月 17 日工程；完整源码包本身已经包含所有改动，无需再次应用补丁。
